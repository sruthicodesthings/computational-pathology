Overview

Designed a computational workflow to transform high-resolution fluorescence microscopy images into spatially registered measurements of mouse-brain pathology for ongoing biological investigation.

Responsibilities included approximately 12,000 manually traced polygons, image preprocessing, iterative segmentation training, storage-constrained GPU inference, atlas-coordinate correction, and documented handover.

Pipeline

OMERO → QuPath annotations → preprocessing / tiles
      → MONAI Attention U-Net on GPU → masks / polygons
      → QuPath + ABBA → Allen CCFv3 coordinates
      → spatial reference matching → volume estimates

Images were hosted separately from GPU compute; the workflow processed brains in batches and retrieved outputs before clearing temporary compute storage.

Limitations

Segmentation performance was not independently reproduced for this portfolio. Tile-level splits may overstate unseen-brain generalization. Spatially nearby reference cells do not establish cell identity. Biological interpretation remained with the laboratory.
