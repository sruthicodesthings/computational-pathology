- [ ] Keep original reports and internal runbooks outside this repository.
- [ ] Remove EPFL hostnames, usernames, project IDs, registry addresses, storage mounts, private image names and any credentials from every file and Git history.
- [ ] Confirm all illustrations and example data are synthetic or appropriately licensed.
- [ ] Decide whether historical aggregate metrics may be shared; otherwise replace with methodology-only descriptions.
- [ ] Review all code for lab-specific configuration, embedded tokens and confidential identifiers.
- [ ] Review the site with the understanding that `noindex` does not secure it.
- [ ] Share only a separate, sanitized static export via an unlisted link; keep the source repository private.
